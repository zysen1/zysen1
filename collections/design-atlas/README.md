# 设计审美参考站

做片头、搭网页、给产品找材质时，打开一个站就能开始练习。这里收录 112 个入口，每个网站都配了一件可以亲手做的小事。

**来源**　前 100 项的选站、顺序和九个分类来自 Eian Lu 的文章。原编号和原链接均保留，中文练习为本清单另写。第 101–112 项为本次增补。[阅读 Eian 的原帖](https://x.com/EianLu/status/2121219503988113557) · [文章《100 个提升审美的设计网站大赏》](https://x.com/i/article/2121110864367661056)

**打开可搜索目录**　在 [index.html](index.html) 的 GitHub 文件页选择 **Download raw file**，保存后双击，即可在本地按名称、分类和用途查找。

**带走这份清单**　在文件页选择 **Download raw file** 下载 [bookmarks.html](bookmarks.html)，在浏览器的书签管理中选择“从 HTML 文件导入”，即可得到分好类的书签。做知识库或接自己的工具，可直接取 [catalog.json](catalog.json)。
